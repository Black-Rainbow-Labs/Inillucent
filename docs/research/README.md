# Research

Each page in this folder is one study: a question about how inillucent should work, measured on
real data, with every result and the decisions each result led to. The same studies are published
at [inillucent.com/research](https://inillucent.com/research).

A study reports what it measured. It does not change a default by itself. Where a study led to a
feature, the study says which feature and why, and the feature's own page says how to use it.

| Date | Study | What it answers |
|---|---|---|
| 29 September 2026 | [Retrieval for RAG](rag-retrieval-study.md) | Which search techniques put the right text in front of a language model, measured on 67,369 emails with 119 graded questions, and what inillucent built because of each result |

[Retrieval for RAG, explained from the start](../rag-explained.md) teaches the same techniques to a
beginner and runs the recommended setup with every command and its output.
